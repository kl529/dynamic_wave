01 · 메인 첫 화면 (데스크톱)

앱을 열면 바로 할 일이 보인다

/ · 1440px

요청사항

장기 복리 기준으로 전략을 다시 정하고 앱도 고쳐 주세요.

배경

레거시 엔진(dongpaEngine.ts)이 모드 설정을 찾지 못해 TypeError로 화면 전체가 멈췄습니다.

수정 내용

레거시 엔진과 거래 내역 탭을 없애고, 추천 전략 탭을 첫 화면으로 두었습니다.

비교 기준

Before: 마지막 커밋(d20b1f9)을 별도 worktree에서 dev 서버로 실행. After: 작업 트리 프로덕션 빌드(next start). 둘 다 로그인 후 같은 시각(2026-10-30, 데이터 2026-10-29 종가), 크롬 헤드리스, 라이트 테마.

03 · 동파법 탭

이미 끝난 날의 신호 대신 다음 장 주문표

/ 동파법 탭 · 1440px

요청사항

동파법도 백테스트와 같은 방식으로 실행돼야 합니다.

배경

기존 로직은 마감된 날의 등락률로 “매수 신호”를 띄웠습니다. 백테스트는 그날 종가 체결을 가정해 실제 실행과 어긋났습니다.

수정 내용

다음 정규장에 넣을 LOC/MOC 주문(분할·수량·지정가·조건)을 엔진과 같은 규칙으로 보여줍니다.

비교 기준

Before: 마지막 커밋(d20b1f9)을 별도 worktree에서 dev 서버로 실행. After: 작업 트리 프로덕션 빌드(next start). 둘 다 로그인 후 같은 시각(2026-10-30, 데이터 2026-10-29 종가), 크롬 헤드리스, 라이트 테마. 매매 기록 DB가 연결되지 않아 분할은 초기 상태입니다.

04 · 백테스트 핵심 지표

손절을 빼고 계산하던 승률을 바로잡음

/backtest · 2026-08-01~10-30 · 기본 설정

요청사항

검증 수치를 믿을 수 있어야 합니다.

배경

승률·기대값이 손절 거래를 빼고 계산돼 손실이 있어도 승률 100%로 보였습니다. 매매한 날 총자산이 틀리게 합산됐고, LOC 체결가·RSI 모드 미래 데이터 문제도 있었습니다.

수정 내용

청산 전체로 승률을 계산하고 엔진을 고쳤습니다. 같은 기간 수익률 -16.7% → -1.5%, MDD 36.7% → 12.6%로 바뀌었습니다.

비교 기준

Before: 마지막 커밋(d20b1f9)을 별도 worktree에서 dev 서버로 실행. After: 작업 트리 프로덕션 빌드(next start). 둘 다 로그인 후 같은 시각(2026-10-30, 데이터 2026-10-29 종가), 크롬 헤드리스, 라이트 테마.

05 · 백테스트 설정 화면

데이터 부족 경고 제거

/backtest · 1440px

요청사항

짧은 기간도 RSI 모드가 맞게 계산돼야 합니다.

배경

선택 기간 데이터만으로 주간 RSI를 계산해 앞부분이 늘 안전모드였고, 이를 경고로 안내했습니다.

수정 내용

시작일 이전 500거래일로 RSI를 미리 계산해 경고가 필요 없어졌습니다. 하이브리드 설명에 표본 외 실패를 적었습니다.

비교 기준

06 · 백테스팅 추천 전략

추천 전략을 기간·설정을 바꿔 직접 돌려본다

/backtest · 1440px · 기본 설정(2006-07-01~, QLD, 100~300일, 매일, 세금 반영)

요청사항

앱 백테스팅에서 QLD 전략도 돌려볼 수 있게 해 주세요.

배경

백테스팅 화면은 동파법만 지원했고, 추천 전략 결과는 보고서로만 볼 수 있었습니다.

수정 내용

상단에서 전략을 고르고 상품·이동평균·조정 주기·세금을 바꿔 실행합니다. 결과는 같은 기간 QLD 보유·S&P500 보유와 비교하고, 보유 비중 변화를 함께 보여줍니다.

비교 기준

After 수치는 검증 스크립트와 같은 함수로 계산한다. 2010-03-11 시작으로 돌리면 보고서와 같은 세후 16.7%가 나온다 (화면에서 확인).
